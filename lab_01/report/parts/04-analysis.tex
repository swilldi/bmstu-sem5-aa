\chapter{Аналитическая часть}
В данной лабораторной работе решается задача поиска элемента в массиве. Дан массив $array$ из $N$ различных элементов и искомое значение $t$. Требуется найти индекс элемента массива, равного $t$, либо установить, что такого элемента в массиве нет.

Для решения задачи рассматриваются следующие алгоритмы:
\begin{itemize}
	\item поиск полным перебором;
	\item бинарный поиск.
\end{itemize}

\section{Вывод}
В результате аналитической части была поставлена задача поиска элемента в массиве и определены алгоритмы для её решения~--- поиск полным перебором и бинарный поиск.
